# 0070 Documentation Reality Alignment

## Status

Accepted

## Context

README claims should match tested behavior.

## Decision

Maintain a verified checklist and limitations section in README. Claims about user workflows must have unit, e2e, or smoke coverage, or be removed.

## Consequences

The README becomes less flashy and more trustworthy.

## Alternatives Considered

- Keep aspirational claims: rejected because Phase 3 prioritizes stranger usability.
