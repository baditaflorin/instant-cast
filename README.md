# Instant Cast

Live site: https://baditaflorin.github.io/instant-cast/

Repository: https://github.com/baditaflorin/instant-cast

Support: https://www.paypal.com/paypalme/florinbadita

Instant Cast is a no-account screen recorder with webcam overlay, on-device transcription, and encrypted expiring share links.

## Quickstart

```sh
npm install
make dev
```

The production frontend is built into `docs/` so GitHub Pages can serve it directly.

## Architecture

See `docs/architecture.md` and `docs/adr/`.

## Development

```sh
make help
make install-hooks
make test
make build
make smoke
```
